# MinusCorrect 10-Domain Pre-Launch Security & Operational Audit Skill

MinusCorrect provides an automated, adversarial pre-launch audit specifically engineered to catch the 10 most common catastrophic vulnerabilities in AI-generated and full-stack systems.

## When to Activate

- Auditing a repository before production deployment or public launch
- Reviewing code generated by vibe-coding platforms (Cursor, v0, Lovable, Claude)
- Checking for sensitive credential leaks, missing Supabase Row-Level Security, or unindexed foreign keys
- Ingesting external SAST/DAST findings to synthesize staged reproduction contracts

---

## The 10 Audit Domains

1. **DOM-01: Secret Leakage & Bundling**: Catches `NEXT_PUBLIC_` exposing private backend service keys (e.g. `service_role` secrets, Stripe private keys).
2. **DOM-02: Missing Row-Level Security (RLS)**: Verifies that every Supabase/PostgreSQL table has `ENABLE ROW LEVEL SECURITY`.
3. **DOM-03: BOLA / IDOR Traps**: Flags direct object references without tenant scoping (`where user_id = auth.uid()`).
4. **DOM-04: Server Action Execution Without Auth**: Detects Next.js `"use server"` actions callable directly without authentication checks.
5. **DOM-05: SECURITY DEFINER View Traps**: Identifies Postgres views created with `SECURITY DEFINER` that bypass user RLS policies.
6. **DOM-06: Webhook Signatures & Idempotency**: Audits webhook handlers for HMAC signature validation and idempotency key checks.
7. **DOM-07: Unindexed Foreign Keys**: Catches unindexed foreign keys that cause full table lockups under production load.
8. **DOM-08: Staging SEO & Robots.txt**: Ensures non-production environments have `Disallow: /` to prevent indexing staging data.
9. **DOM-09: Plaintext Sensitive Logging**: Flags `console.log` or logging statements emitting tokens, passwords, or PII.
10. **DOM-10: Serverless Spend Limits & Timeouts**: Checks serverless functions for unbounded execution timeouts or missing spend limits.

## Core Commands & Workflows

### 1. Run Automated Pre-Launch Audit
```bash
minuscorrect audit --pre-launch
```
For machine-readable JSON:
```bash
minuscorrect audit --pre-launch --json
```

### 2. Ingest External Security Findings
```bash
minuscorrect audit snyk_findings.json --output-dir tests/staging
```
Synthesizes executable reproduction test contracts in `tests/staging/` to verify that identified vulnerabilities are remediated before launch.
