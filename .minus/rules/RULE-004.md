# RULE-004: Refero Design System Invariant

- **Scope**: `frontend`
- **Enforcement**: `strict`

## Invariant Instruction for Autonomous Agents
All UI elements must utilize Tailwind CSS v4 design tokens and CSS custom properties with WCAG AA compliance.

## Prohibited Patterns & Anti-Patterns
- `@theme`
- `--color-`
